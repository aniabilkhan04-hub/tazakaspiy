# 🌊 Эко-Атырау (Python-версия)

Краудсорсинговая карта эко-инициатив города Атырау + Telegram-бот для волонтёров.
Бэкенд полностью на **Python** (Flask + python-telegram-bot). Фронтенд (карта, HTML/CSS/JS)
не меняется — браузеру не важно, на чём написан сервер.

- **Сайт с картой** — Leaflet-карта города Атырау: свалки, убранные места, пункты переработки,
  эко-магазины, места для посадки деревьев, плюс рейтинг волонтёров.
- **Telegram-бот** — весь сценарий на кнопках: волонтёр жмёт кнопку, присылает фото и
  геолокацию, заявка уходит на модерацию.
- **Панель модерации** (`/admin.html`) — администратор одобряет/отклоняет заявки. При одобрении
  «Я убрал мусор» волонтёру начисляется рейтинг, видимый на сайте.

> Используется SQLite вместо PostgreSQL/PostGIS — не нужен отдельный сервер БД, проект
> запускается сразу.

## 1. Установка

Понадобится **Python версии 3.10 или новее** ([скачать здесь](https://www.python.org/downloads/)).

```bash
# 1. Распакуйте архив и перейдите в папку проекта
cd eco-atyrau-py

# 2. Создайте виртуальное окружение
python3 -m venv .venv

# 3. Активируйте его
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 4. Установите зависимости
pip install -r requirements.txt

# 5. Создайте файл настроек .env на основе примера
cp .env.example .env      # Windows: copy .env.example .env
```

Откройте `.env` и заполните:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
PORT=3000
ADMIN_PASSWORD=придумайте_свой_пароль
```

### Как получить токен Telegram-бота
1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, следуйте инструкциям (укажите имя и username бота).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxx` — вставьте его в `.env`.

Если не указать токен, сайт всё равно будет работать — просто бот не запустится.

## 2. Запуск

```bash
python run.py
```

В консоли появится:

```
🌍 Сайт запущен: http://localhost:3000
🛠  Панель модерации: http://localhost:3000/admin.html
🤖 Telegram-бот запущен
```

- Откройте **http://localhost:3000** — карта города Атырау.
- Откройте **http://localhost:3000/admin.html** — панель модерации (пароль из `.env`).
- Найдите вашего бота в Telegram и нажмите **Start**.

## 3. Как пользоваться ботом (для волонтёров)

После `/start` бот показывает кнопки:

| Кнопка | Что происходит |
|---|---|
| 📸 Сообщить о свалке | Прислать фото + геолокацию несанкционированной свалки |
| ✅ Я убрал мусор | Прислать фото убранного места + геолокацию — после одобрения +1 к рейтингу |
| ♻️ Пункт переработки | Отметить на карте пункт приёма вторсырья |
| 🌳 Место для посадки дерева | Отметить подходящее для посадки место |
| 🛍 Эко-магазин | Отметить магазин с эко-товарами |
| 🏆 Мой рейтинг | Посмотреть текущее количество очков |

Каждый сценарий: **фото → геолокация → короткое описание (можно пропустить)** — всё через кнопки.

---

## 4. Модерация

На `/admin.html` администратор видит все заявки со статусом «на рассмотрении»: фото, описание,
кто отправил. Кнопки **«Одобрить»** и **«Отклонить»**:
- одобренная точка сразу появляется на карте сайта;
- если это заявка «Я убрал мусор» — автору начисляется +1 к рейтингу, который виден в таблице
  лидеров на главной странице.

## Хостинг (бесплатно)

**Netlify умеет только статику** (папка `public/`). Flask-сервер, SQLite и Telegram-бот
(`python run.py`) на нём не работают, поэтому схема такая:

| Часть | Где | Цена |
|---|---|---|
| Сайт (`public/`) | Netlify (`netlify.toml` уже настроен) | бесплатно |
| Бэкенд + бот (`python run.py`) | Render (Web Service, Free) или свой ПК + Cloudflare Tunnel | бесплатно |

1. Залейте проект на GitHub (файлы `.env`, `eco.db`, `.venv` уже в `.gitignore`).
2. Render → New Web Service → ваш репозиторий. Build: `pip install -r requirements.txt`,
   Start: `python run.py`. В Environment добавьте `TELEGRAM_BOT_TOKEN`, `BOT_USERNAME`, `ADMIN_PASSWORD`.
3. В `netlify.toml` замените `ВАШ-БЭКЕНД.onrender.com` на адрес вашего сервиса Render.
4. Netlify → Add new site → Import from Git (Publish directory: `public`).
5. Чтобы бесплатный Render не «засыпал» (вместе с ним спит и бот), настройте на
   [UptimeRobot](https://uptimerobot.com) бесплатный пинг `https://ВАШ-БЭКЕНД.onrender.com/healthz` раз в 5 минут.

⚠️ На бесплатном Render диск временный: **при перезапуске и деплое `eco.db` и `uploads/` стираются**.
Для постоянного хранения нужна внешняя БД (например, Neon/Supabase) и хранилище фото (Cloudinary).

## 5. Структура проекта

```
eco-atyrau-py/
├── run.py               — точка входа (запускает сайт + бота)
├── server/
│   ├── app.py            — Flask-сервер и REST API
│   ├── bot.py              — логика Telegram-бота (python-telegram-bot)
│   └── db.py                 — база данных SQLite и функции доступа к ней
├── public/
│   ├── index.html           — страница с картой
│   ├── admin.html           — панель модерации
│   ├── css/                 — стили
│   └── js/                  — фронтенд-логика (Leaflet, рейтинг, модерация)
├── uploads/                 — сюда сохраняются фото из бота
├── requirements.txt
└── .env.example
```

## 6. Смена стека на PostgreSQL/PostGIS (опционально)

Меняется только `server/db.py` (например, на SQLAlchemy + psycopg2). Остальной код — Flask-роуты,
бот, фронтенд — работает с теми же полями `lat`/`lon`/`type`/`status` и не потребует переделки.
